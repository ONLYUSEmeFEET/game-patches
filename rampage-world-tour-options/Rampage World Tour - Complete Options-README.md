# Rampage: World Tour — Complete Options (Game Boy Color)

ROM hack / IPS patch for **Rampage: World Tour** (Game Boy Color).

## Files
- `Rampage World Tour - Complete Options.ips` — Standalone IPS patch (1,772 bytes)
- `build_patch.py`, `asm.py`, `rom_data.py` — Patch build scripts

## Patching
Apply `Rampage World Tour - Complete Options.ips` to an unmodified copy of:
- `Rampage - World Tour (USA, Europe).gbc` (`524,288` bytes, SHA-256 `1a8bfa0e55e89241a9843e440e8e...`)

Use [Floating IPS (Flips)](https://www.romhacking.net/utilities/1040/) or [RomPatcher.js](https://www.marcrobledo.com/RomPatcher.js/).
